# Synthetic Phase 2 Fixtures

These four DOCX resumes and the sparse PDF are synthetic test data created only for this project. They contain placeholder contact details using `example.invalid` and reserved test phone numbers. They are not real people and must remain visibly labeled as synthetic.

The fixtures are reproducible with:

```powershell
.\.venv\Scripts\python.exe scripts/create_phase2_fixtures.py
```
